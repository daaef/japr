Revision scenarios

Revision requested by editor

Task Action / Change Expected Result Failure Indication
Editor requests revisions Click Request revisions, enter revision letter Expected Status becomes changes_requested; author notification links to submission Failure Button missing when consensus suggests revision, status not updated
Author sees requested changes Author opens submission page Expected Editorial note shown; reviewer field-level requests have input fields; document-level requests shown as guidance Failure Requests missing, no input for title/abstract/description, document-level not visible
Author resolves field-level requests Fill inputs and click Submit change updates Expected Submitted fields marked resolved; editor notified; unresolved fields remain pending Failure Updates not saved, all requests marked resolved prematurely, status jumps unexpectedly
Author uploads revised file Click Upload revision file, then Submit a revision Expected New version created; review round increments; status returns to pending; editor notified Failure File not attached, version missing, round did not increment, editor not notified

Minor revision vs. major revision

Task Action / Change Expected Result Failure Indication
Reviewer selects minor revision Recommendation set to minor_revision Expected Recommendation stored; consensus shows revision if any reviewer requested it Failure Recommendation not saved, consensus ignores revision
Editor's revision letter states scope Editor describes required changes in revision request Expected Author sees the letter as an editorial note and acts accordingly Failure Letter missing from author view, not stored on manuscript

Edge cases

Reviewer declines invitation

Task Action / Change Expected Result Failure Indication
Reviewer declines Click Decline Expected Editor receives notification; replacement reviewer can be assigned Failure Reviewer shown as still pending, editor cannot assign replacement

Deadline extension request

Task Action / Change Expected Result Failure Indication
In-progress reviewer requests extension Enter reason and click Request extension Expected Editor sees request in Pending extension requests card Failure Request not listed, editor not notified
Editor approves extension Click Approve extension Expected Reviewer deadline moves forward by 7 days; reviewer receives notification with link Failure Deadline unchanged, reviewer not notified

Quorum not met (reviewed status)

Task Action / Change Expected Result Failure Indication
All assigned reviewers responded but fewer than 3 completed 2 completed + 1 declined Expected Status becomes reviewed; editor sees approve/request-revisions/decline options; no consensus hint Failure Status becomes notice state or request-revisions button missing

Inconclusive consensus

Task Action / Change Expected Result Failure Indication
3 completed reviews split accept/reject No revision recommendation among completed reviews Expected Consensus shows Inconclusive; managing editor chooses approve or decline Failure Consensus shows wrong label or no decision buttons

Task Action / Change Expected Result Failure Indication
